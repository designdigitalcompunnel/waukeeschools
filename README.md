# Waukee Community School District — Homepage Prototype

This is a front-end homepage concept adapted from the supplied Idaho AEYC template for Waukee Community School District.

## Files
- `index.html` — homepage structure and content
- `styles.css` — Waukee purple/lime/lavender theme, responsive styles, motion and accessibility refinements
- `script.js` — mobile navigation, scroll progress, reveal effects and count-up animation
- `assets/waukee-logo.png` — Waukee CSD logo
- `assets/compunnel-logo.svg` — supplied Compunnel logo used in the footer as a design-credit mark

## Preview
Open `index.html` in a browser. The hero video and stock photography use external URLs and need an internet connection. If the video source is unavailable, the hero poster image remains as a fallback.

## Content / IA notes
The page is organized around the public user tasks in the Waukee CSD RFP: finding schools, family/student resources, calendars, menus, district information, community details, news/events, employment and contact details. Staff intranet content is not represented as a public page. Contact details use the district administration address and phone; the RFP email is labeled as the RFP contact.

This is a prototype, not an official district website. Social profile URLs, content, imagery and the third-party video source should be confirmed by WCSD before production. Accessibility requires manual testing beyond CSS font-size and focus-state checks.
